## Definition of pilot-ready

The application is pilot-ready only when authentication, RLS, safeguarding access restrictions, enrollment, attendance, core learning records, transition tracking, backup procedures and role tests have been verified with realistic test data. No real child safeguarding case data should be entered before the restricted safeguarding module and its access controls are tested.
